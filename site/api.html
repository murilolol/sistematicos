Mapa de rotas (recorte)

Autorização não é por rota — é um middleware aplicado uma vez na entrada. "Sessão" basta um cookie válido; "Dono ou admin" também confere posse do recurso; "Admin" restringe a ADMIN_RAS; "Pública" não exige nada.

MétodoRotaAutorizaçãoPropósito
POST/api/loginPúblicaLogin real contra o portal FEF
GET/api/fef/cursosPúblicaEspelho dos cursos do site institucional
GET/api/boletimSessãoNotas e frequência, ao vivo
POST/api/mensalidade/pixSessãoGera QR Code PIX dinâmico
DELETE/api/tasks/:idDono ou adminApaga uma tarefa do Kanban pessoal
DELETE/api/accountSessão (própria conta)Exclusão/anonimização LGPD self-service
POST/api/admin/adminsAdminGestão de administradores da plataforma

Chamando a API

A única rota segura para testar sem sessão é a pública. Em Python, TypeScript ou cURL, a chamada é a mesma coisa: um GET comum.

cliente.pypython
import requests

resp = requests.get(
    "https://sistematicos.site/api/fef/cursos",
    timeout=10,
)
resp.raise_for_status()

for curso in resp.json():
    print(f"{curso['title']} -> {curso['url']}")
cliente.tstypescript
interface Curso {
  title: string;
  url: string;
  icon: string;
}

async function listarCursos(): Promise<Curso[]> {
  const res = await fetch("https://sistematicos.site/api/fef/cursos");
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}

O padrão de autorização, em código

O trecho real de server/index.js que protege as rotas "dono ou admin" — o RA vem do cookie de sessão, nunca do corpo da requisição.

server/index.jstypescript
const getAuthRa = (req) => req.fefSession?.ra || null;

// Rejeita a menos que o RA da sessão seja o dono do recurso, ou admin.
const requireOwnRaOrAdmin = (extractTargetRa) => (req, res, next) => {
  const ra = getAuthRa(req);
  const targetRa = extractTargetRa(req);
  if (!ra || !targetRa || (ra !== String(targetRa) && !ADMIN_RAS.includes(ra))) {
    return res.status(403).json({ error: 'Acesso negado' });
  }
  req.authRa = ra;
  next();
};

// Uso: extractTargetRa lê o dono real do recurso, não um campo do cliente.
app.delete(
  '/api/tasks/:id',
  requireOwnRaOrAdmin((req) => tasks.find((t) => t.id === req.params.id)?.ra),
  deleteTaskHandler
);
